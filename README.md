# 贪吃蛇（网页版）

这是一个**开箱即玩**的网页版贪吃蛇小游戏，无需构建工具。

## 运行方式

### 方式 1：直接打开
1. 在文件管理器中找到 `index.html`。
2. 双击用浏览器打开即可运行。

### 方式 2：本地静态服务器（推荐）
在项目根目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

- <http://127.0.0.1:8000/index.html>

## 操作说明

- 键盘：方向键 或 `W/A/S/D`
- 空格：开始 / 暂停
- 按钮：点击“重新开始”重置游戏
- 触屏：使用页面上的 `↑ ← ↓ →` 按钮控制方向

## 游戏规则

- 吃到食物会加 1 分，蛇身增长。
- 撞墙或撞到自己游戏结束。
- 最高分会保存在浏览器 `localStorage` 中。
